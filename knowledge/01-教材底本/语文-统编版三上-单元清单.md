## 二、单元结构

> 以下结构由电子课本网（2025 秋版目录）、聊城市智慧教育平台（统编版 2024 三年级上册课程目录）、二一教育教研资料三源交叉核对得出，三源一致。带 `*` 者为略读课文。

### 第一单元 · 学校生活

| 项 | 内容 |
|---|---|
| 课文 | 1 大青树下的小学；2 花的学校；3* 不懂就要问 |
| 口语交际 | 我的暑假生活 |
| 习作 | 猜猜他是谁 |
| 语文园地 | 语文园地一（含"日积月累"） |

**核心知识点**
1. **有新鲜感的词句** — 能找出课文中用词生动、句式特别、有画面感的句子，并说出"新鲜"在哪里。
2. **边读边想象画面** — 读描写性语句时，能在脑中还原场景，并用语言描述出来。
3. **人物特点的外貌描写** — 抓住一两个突出特征写人，不写成"眼睛鼻子嘴"的清单。
4. **略读课文的学习方式** — 略读课文不逐字讲，靠自己读通、抓大意（《不懂就要问》首次出现）。

**常见错误**：把"新鲜感"理解成"没见过的生词"；写人时特征堆砌、没有具体事例；摘抄时只抄词不抄句。

### 第二单元 · 金秋时节

| 项 | 内容 |
|---|---|
| 课文 | 4 古诗三首（山行·杜牧 / 赠刘景文·苏轼 / 夜书所见·叶绍翁）；5 铺满金色巴掌的水泥道；6 秋天的雨；7* 听听，秋的声音 |
| 习作 | 写日记 |
| 语文园地 | 语文园地二 |

**核心知识点**
1. **古诗中的季节意象** — 由枫叶、残荷、橙黄橘绿、秋风、促织等物候判断季节，说出诗人心情。
2. **多种方法理解难懂词语** — 查字典、联系上下文、拆词素、联系生活经验、找近义词，至少掌握四种。
3. **日记的规范格式** — 首行写日期、星期、天气，正文记当天真实见闻与感受。
4. **比喻与拟人** — 识别并仿写，如"水泥道像铺上了一块彩色的地毯"。

**常见错误**：古诗默写错字（"擎雨盖""篱落""萧萧"）；日记写成流水账或编造事件；把"橙黄橘绿"理解成颜色词而非时令。

### 第三单元 · 阅读策略：预测

| 项 | 内容 |
|---|---|
| 课文 | 8 总也倒不了的老屋；9* 犟龟；10* 小狗学叫 |
| 口语交际 | 名字里的故事 |
| 习作 | 续写故事 |
| 语文园地 | 语文园地三（含"交流平台"，总结预测方法） |

**核心知识点**
1. **依题目预测** — 从标题推测故事内容与走向。
2. **依插图预测** — 用插图细节推断情节。
3. **依情节线索预测** — 抓住反复结构、人物性格、前文伏笔推断后文。
4. **预测要有依据，且允许与原文不同** — 重点是"说出你为什么这样猜"，不是猜对。
5. **续写故事** — 顺着已有情节合理往下写，保持人物性格一致。

**常见错误**：只猜结果不说理由；认为"猜错就是错"；续写时人物性格突变、情节与原文脱节。

> 这是**策略单元**，不是普通阅读单元。教法与考法都不同——考的是"预测过程和依据"，不是"记住故事内容"。现有旧版课件把这一单元排到了第四单元，顺序错了。

### 第四单元 · 童话世界

| 项 | 内容 |
|---|---|
| 课文 | 11 宝葫芦的秘密（节选）；12 在牛肚子里旅行；13* 一块奶酪 |
| 习作 | 我来编童话 |
| 快乐读书吧 | 在那奇妙的王国里（推荐《安徒生童话》《稻草人》等） |
| 语文园地 | 语文园地四 |

**核心知识点**
1. **童话的拟人化与想象** — 动植物、器物有人 的情感与行为，且合乎其本来特性。
2. **童话人物与道理** — 从人物行为中读出品质或教训，不贴标签式说教。
3. **科学童话的知识性** — 《在牛肚子里旅行》以反刍过程为骨架，故事性服务于知识性。
4. **编童话三要素** — 角色 + 愿望（或困难）+ 情节转折，缺一不可。

**常见错误**：编童话只罗列角色不设冲突；拟人化不合事物特性（如"石头飞起来唱歌"）；把童话写成说明文。

### 第五单元 · 习作单元：留心观察

| 项 | 内容 |
|---|---|
| 课文 | 14 搭船的鸟；15 金色的草地 |
| 习作例文 | 我家的小狗；我爱故乡的杨梅 |
| 习作 | 我们眼中的缤纷世界 |
| 其他 | 单元内含"梳理与交流""初试身手" |

**核心知识点**
1. **多感官观察** — 视觉、听觉、触觉、嗅觉并用，不停留在"看到"。
2. **连续观察与变化记录** — 同一对象在不同时间的差异（草地早晚变色）。
3. **抓住事物独特之处** — 写"这一只"，不写"这一类"。
4. **观察记录表的使用** — 时间 / 对象 / 变化 / 我的发现。

**常见错误**：观察写成说明介绍；只有视觉一个维度；把连续观察写成一次性印象。

> 这是**习作单元**，教材编排逻辑与普通单元不同：先给例文，再"初试身手"，最后成篇。知识点拆分要跟着这个顺序走。

### 第六单元 · 祖国山河

| 项 | 内容 |
|---|---|
| 课文 | 16 富饶的西沙群岛；17 海滨小城；18 美丽的小兴安岭；19* 香港，璀璨的明珠 |
| 习作 | 这儿真美 |
| 语文园地 | 语文园地六 |

**核心知识点**
1. **找关键语句** — 识别段落的中心句，判断其在段首、段中还是段尾。
2. **围绕一个意思写** — 一段话只讲一件事，句句为此服务。
3. **总分结构** — 先总说后分说，分说部分有顺序（方位、时间、类别）。
4. **按方位顺序写景** — 由远及近、由上到下、由外到内。

**常见错误**：找不到中心句（误把细节句当中心句）；一段话里塞多个主题；写景缺少顺序、空间混乱。

> 《香港，璀璨的明珠》为新增篇目，爱国主义主题，旧版无此课。

### 第七单元 · 自然之美

| 项 | 内容 |
|---|---|
| 课文 | 20 古诗三首（鹿柴·王维 / 望天门山·李白 / 饮湖上初晴后雨·苏轼）；21 大自然的声音；22 读不完的大书 |
| 口语交际 | 身边的"小事" |
| 习作 | 我有一个想法 |
| 语文园地 | 语文园地七 |

**核心知识点**
1. **古诗意境与动静结合** — "空山不见人，但闻人语响"以声衬静；"两岸青山相对出"以动写静。
2. **拟声词与生动语言** — 风声、水声的摹写，积累并仿写。
3. **段落中心句** — 与第六单元衔接，进一步巩固。
4. **提出想法并说明理由** — 针对身边问题，说清"什么问题—什么建议—为什么"。

**常见错误**：《鹿柴》的"柴"读 zhài 不读 chái；"返景"的"景"读 jǐng（通"影"）；提想法时只有抱怨没有建议。

> 《读不完的大书》为新增篇目，旧版无此课。

### 第八单元 · 美好品质

| 项 | 内容 |
|---|---|
| 课文 | 23 司马光；24 一定要争气；25 手术台就是阵地；26* 一个粗瓷大碗 |
| 口语交际 | 请教 |
| 习作 | 那次经历真难忘 |
| 语文园地 | 语文园地八 |

**核心知识点**
1. **文言文初识** — 《司马光》是小学阶段第一篇文言文，重点在读出节奏、借助注释理解，不要求逐字翻译。
2. **带着问题默读** — 默读不出声、不指读，边读边想指定问题。
3. **通过具体事例表现人物品质** — 不空喊"他很勇敢"，而写他做了什么。
4. **叙事的六要素** — 时间、地点、人物、起因、经过、结果。

**常见错误**：把文言文当现代文直译；默读时出声或指读；写人只写评价不写事；叙事缺"结果"或"经过"过简。

> 《一定要争气》《一个粗瓷大碗》为新增篇目，旧版无此课。

## 三、全册能力轴

把八个单元横向拉通看，三年级上册实际在训练四件事：

| 能力轴 | 承载单元 | 说明 |
|---|---|---|
| **词句积累与理解** | 一、二、七 | 从"新鲜感"到"多种方法理解"再到"生动语言"，是同一根线的三级 |
| **阅读策略** | 三、六、八 | 预测 → 找关键语句 → 带着问题默读，策略逐级加码 |
| **观察与写景** | 五、六、七 | 观察 → 围绕一个意思写 → 提出想法，从"看到"到"写出" |
| **叙事与写人** | 一、四、八 | 写人 → 编故事 → 写难忘经历，从虚构到真实 |

**这个轴比单元顺序更重要**。补漏时应按能力轴补，而不是按单元号从头刷——孩子可能第三单元（预测）弱，但第一单元（新鲜感词句）已经不构成问题。
