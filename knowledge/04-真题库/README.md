# 真题库

> 用途：存放真实试卷，作为出题的参照依据。**所有新出的题，只要参考了真题，都要在题目数据里标注来源。**

---

## 一、怎么把真题给我

### 方式一：直接发图片

拍照或截图发我，我用 OCR 读出来，再整理成文字版存进本目录。

拍照建议：整卷一张一张拍，保证四角完整、字迹清晰；有答案的那一页也拍上。

### 方式二：粘贴文字

把题目文字直接贴给我，我按下面的格式整理。

### 方式三：自己放进目录

在本目录新建 Markdown 文件，按下面命名：

```
2025-苏州-三上-期末-XX小学.md
2025-江苏-三上-期中-XX区统考.md
```

## 二、单个真题文件的格式

```markdown
# 2025 秋 · 苏州 XX 小学 · 三年级上册期末卷

- 来源：家长提供 / 学校下发
- 时间：70 分钟
- 满分：100 + 附加 10
- 录入日期：2026-10-26

## 一、直接写出得数（8 题 × 1 分）

1. 40×7=
2. 500×8=
...

## 二、竖式计算（4 题 × 3 分）

1. 265×4=
...

## 三、填空（10 题 × 2 分）

1. 计算 3×192+47 时，先算（　）法，再算（　）法。
...

## 四、选择（6 题 × 2 分）

...

## 五、操作题（2 题 × 3 分）

...

## 六、解决问题（5 题 × 6 分）

...

## 七、附加题（2 题 × 5 分）

...

## 参考答案

...

## 值得注意的地方

- 第 X 题考的是"多余条件干扰"，孩子容易误用
- 第 Y 题需要先统一单位
```

最后那一节很重要——**你对这份卷子的观察**，比题目本身更有用。哪些题孩子错了、错在哪、老师强调了什么，都写进去。

## 三、出题时怎么用

题目数据里加一个 `ref` 字段指向真题文件：

```python
{"type": "input", "level": "challenge",
 "question": "...",
 "answer": "...",
 "explanation": "...",
 "ref": "2025-苏州-三上-期末-XX小学 第6题"}
```

这样每道题都能追溯它参考了哪份真题的哪道题，不会变成凭空编的题。

## 四、已在用的真题特征（持续补充）

目前从公开渠道整理到的江苏/苏教版三年级上册期末卷特征，已用于期末卷设计：

| 特征 | 说明 | 来源 |
|---|---|---|
| 卷面结构 | 计算 → 填空 → 选择 → 操作 → 解决问题 → 附加题 | 多份 2025—2026 学年苏教版期末卷 |
| 时间与分值 | 70 分钟，100 分 + 附加题 10 分 | 同上 |
| 计算题占比 | 22—28 分，含口算、竖式（带验算）、脱式 | 同上 |
| 附加题定位 | 明显高于主体难度，多为倍数关系、倒推 | 同上 |
| 高频难点 | 多余条件干扰、隐藏条件、重叠计数、"至少/最多"、靠墙问题、买赠问题 | 多份期末卷与错题分析资料 |
