# 苏州三年级学习工具台 · 方案 v1

> 制定日期：2026-10-26（2026—2027 学年第一学期第 9 周）
> 目标对象：江苏苏州，小学三年级在读学生（当前学期：三年级上册）
> 覆盖科目：语文、数学、英语、体育
> 文档性质：**决策方案，尚未动手实施**

## 零、先说结论

四句话：

1. **版本已核实**：苏州三年级为「语文 统编版 + 数学 苏教版 + 英语 译林版（三年级起点）+ 体育 无教材（依课标与国标体测）」。其中语文、数学、英语三科**均已在 2024—2025 年启用新版教材**，网上一半以上的教辅资料仍是旧版，直接照搬会学错。
2. **不用从零建**：当前工作区已有一个成熟的小学 AI 学习平台工程（聪聪学堂 / ChinaStudyFree 多端工程），具备知识点课、单元测验、SRS 复习、成就与商店等底层能力，已产出 148 本教材内容、13450 道题。工具台应**在这套工程上做"苏州三年级"的定制层**，而不是另起一套。
3. **但硬缺口有三个，必须补**：① 语文三年级上册现有内容是**旧版编排**，与孩子课本对不上；② **苏教版数学三年级全册、译林版英语三年级上册，内容为零**；③ **体育科目完全没有**。
4. **合规红线一条**：按教育部 2025 年 12 月新规，小学三年级学校层面每学期只组织一次期末考试，严禁周考、月考、单元考，且实行等级评价、不排名不公布。所以工具台里的"试卷"必须定位为**自主自测与家庭练习**，不得设计成考试排期、不得做分数排名。

**关于语文版本（已实物确认，2026-10-26 补充）**

孩子语文课本版权页已实拍核对，逐项为：教育部组织编写，人民教育出版社出版，江苏凤凰出版传媒股份有限公司重印发行，**2025 年 6 月第 1 版，2026 年 7 月第 2 次印刷**，ISBN 978-7-107-39754-7，定价 7.54 元，审批号苏费核〔2026〕0266 号，本册主编李明新、伍新春。

1. 用的是**统编版**，不是苏教版。江苏全省语文统一统编版，只有数学用苏教版——这个区分很重要，网上大量资料把"江苏"直接等同于"苏教版"，语文也跟着错。

数学课本版权页实拍核对：**江苏凤凰教育出版社**出版，南京东方数学教育科学研究所与江苏省中小学教学研究室共同编著，本册主编聂艳军，**2025 年 7 月第 1 版，2026 年 7 月第 2 次印刷**，ISBN 978-7-5743-1775-8，定价 7.52 元。

确认是**苏教版**，与语文（统编版）、英语（译林版）三科版本各不相同——这一点在挑资料时最容易搞混，网上不少说法把"江苏"整体当成苏教版，语文英语也跟着错。

| 七 分数的初步认识（一） | 七 **数量关系的分析（一）** |
| 八 期末复习 | 八 **观察物体（二）** |

四处结构性变化需要特别记住：① **"分数的初步认识"整体移出三上**，旧版第七单元在新版完全不存在，这是最常见的踩坑点；② **"长方形和正方形"也移出三上**，旧版第三单元及"周长是多少"专题不再有；③ "千克和克"不再独立成单元，并入第二单元的实践活动"曹冲称象的故事"，并扩展到吨；④ "混合运算"提前到第一单元并与数量关系合并。

**所以标注"苏教版三年级上册"的现有资料，绝大多数是旧版，用前必须先看单元名对不对得上。**

**关于英语版本（已实物确认，2026-10-26 补充）**

英语课本版权页实拍核对：译林出版社出版，主编何锋，副主编王守仁，分册主编张伊娜，**2024 年 7 月第 1 版，2026 年 7 月第 3 次印刷**，ISBN 978-7-5753-0037-7，定价 5.77 元，江苏凤凰出版传媒股份有限公司重印发行。

"第 3 次印刷"这个细节值得注意：2024 年首版，已连续印三轮，正好覆盖 2024 秋、2025 秋、2026 秋，与新版启用时间严丝合缝。

**更重要的一层**：新版译林 3A 的编排逻辑与旧版完全不同，这是本次核对里最需要记下的一条——

| 对比项 | 旧版（2012/2013 审定） | 新版（孩子手上这本） |
|---|---|---|
| 单元逻辑 | 按板块推进，无统一主题问题 | 每单元一个 **Big question** 统领全单元 |
| 板块名 | Story time / Fun time / Cartoon time / Letter time / Ticking time | 课文板块 + **Letters in focus** + 情景板块 + 活动板块 + **Assessment time** |
| 字母教学 | 独立 Letter time 板块 | **Letters in focus** 逐单元滚动 |
| 模块层级 | 无 | **Module 1 / Module 2**，中间插 Project |

所以网上凡是出现 Story time、Cartoon time、Ticking time 的"译林 3A"课件，一律是旧版。这条对工具台的直接影响有三点：① 知识点应按 Big question 拆，不只拆词汇句型；② 26 字母要做独立进度轨，与单元进度并行；③ Assessment time 本身是教材自带的形成性自评，工具台做"单元自评"是顺势而为，不是在增加考试负担。

**重要提示**：数学与英语两科的"新版"不是小修小补，是结构性改版。数学新教材把"分数的初步认识"整体移出三年级上册，把质量单位（千克、克、吨）并入"曹冲称象的故事"实践活动单元；英语新教材把原来的 Unit 顺序、话题全部重排。**任何标注"苏教版三上"的老资料，必须先核对单元名再使用。**

### 2.4 题型缺口

现有 7 种题型，全部是客观题。三年级恰恰是主观题集中出现的年级：

- 语文——习作（8 次）、口语交际、阅读理解长文本、看拼音写词语；
- 数学——**解决问题（应用题）**、动手操作与作图、单位换算；
- 英语——字母书写、听音选图、看图说话、情景对话。

**"作文批改""应用题分步判分"这两类能力，现有题型体系完全不支持。** 这是架构级缺口，需要新增题型与评分逻辑（可复用已有的 AI 后端做批改）。

## 三、工具台总体设计

### 3.1 五层结构

孩子看到的是游戏，家长看到的是数据，底层是同一套东西：

```
第 5 层  学情档案    错题时间轴 · 掌握度热力 · 学期报告
第 4 层  知识积累    字词句段 · 古诗 · 公式 · 词汇 · 体育数据
第 3 层  试卷中心    单元自测 · 专项突破 · 整卷模拟 · 错题重组卷
第 2 层  题型训练    按知识点挂题型，分难度分层
第 1 层  知识图谱    单元 → 知识点 → 掌握状态（未学/学过/熟练/易错）
```

设计原则：**下层不通过，上层不开放**。知识点没做过，不给孩子整卷；整卷错题不归档，不进积累本。这样"刷题"和"积累"才咬得住。

### 3.2 四科差异化骨架

四科不是一个模子，硬套会难受。

**语文——重在"积累 + 输出"**

- 知识图谱：8 单元 × 3–4 个语文要素 = 约 28 个知识点（识字写字、词语理解、预测策略、童话特点、观察方法、关键语句、古诗意象、人物品质）
- 题型训练：看拼音写词语、字音字形辨析、词语搭配、句子仿写与修改、古诗默写、课文填空、课内阅读、课外阅读
- 试卷中心：单元自测卷 + 期末整卷（按"积累与运用 / 阅读 / 习作"三段式）
- 积累本：生字表、词语表、日积月累、古诗 12 首以上、好词好句摘抄、成语归类
- 独有模块：**习作工坊**（8 次习作，AI 给三段式点评：写了什么 / 好在哪 / 改哪里）

**数学——重在"算理 + 建模"**

- 知识图谱：8 单元拆到"算法 + 算理 + 易错点"三层，约 45 个细目
- 题型训练：口算（限时）、竖式计算、脱式计算、填空、判断、**解决问题（两步计算）**、单位换算、动手操作
- 试卷中心：单元卷 + 期末整卷（按"计算 / 填空选择 / 操作 / 解决问题"四段式，接近苏州期末卷结构）
- 积累本：公式与数量关系（总价＝单价×数量、路程＝速度×时间）、单位换算表、错因归类（看错数字/进错位/单位没统一/没读懂题意）
- 独有模块：**口算闯关**（每日 20 题限时，对应现有 jump/stage 机制）、**错因诊断**（不只判对错，判"错在哪一类"）

**英语——重在"听说 + 字母"**

- 知识图谱：8 单元 × 2 个知识点（核心句型 + 词汇群），加"26 字母认读与书写"独立轨道
- 题型训练：字母认读、听音选图（需接 TTS）、图词匹配、情景对话选择、句子排序、看图说一句
- 试卷中心：单元卷 + 期末卷（以听力和情景选择为主，符合零起点定位）
- 积累本：单词卡（图 + 音 + 义）、句型卡、字母书写示范
- 独有模块：**跟读打分**（TTS 示范 + 录音对比，现有 TTS 能力可支撑，需加录音与相似度判断）

**体育——重在"数据 + 坚持"**

这一科没有教材，也就没有"知识点课"，硬做成知识点课会很假。设计成三个模块：

- **体质档案**：6 项成绩录入（BMI、肺活量、50 米、坐位体前屈、1 分钟跳绳、1 分钟仰卧起坐），自动算等级、画趋势曲线、给"距离下一等级还差多少"的具体目标
- **每日运动**：跳绳/仰卧起坐/柔韧/跑步打卡，接现有连击（jump）与成就系统
- **技能与常识**：水平二技能图解（跳绳花样、前滚翻、原地拍球等）+ 健康教育小知识（每天运动时长、用眼卫生、运动安全）

> 评分标准必须按《国家学生体质健康标准》原文录入具体数值表，**不凭记忆填写**。这一项需要单独取一次原始表格。

### 3.3 趣味化机制（复用现有，不新造）

现有工程已有金币、商店、装扮、宠物、连击、排行榜、成就。工具台的趣味化不另起一套，而是把四科行为挂上去：

| 行为 | 奖励 | 说明 |
|---|---|---|
| 完成一个知识点课 | 金币 + 经验 | 已有 |
| 口算限时达标 | 连击倍数 | 已有 jump |
| 连续 7 天运动打卡 | 稀有装扮 | 需新增体育连击 |
| 积累本新增 10 条 | 收藏册解锁 | 需新增 |
| 单元自测全对 | 徽章 | 需新增 |
| 错题重做通过 | 宠物亲密度 | 可接 mascotTriggers |

**关于排行榜**：现有 `league.ts` 是用户间榜单。给孩子用建议改为**与自己的历史比（个人最佳）**，理由是教育部明确规定考试结果不排名不公布，家长端也不该强化比较。这是建议，需你确认。

### 4.2 内容规范

每条知识库记录统一六个字段，缺一不可：

| 字段 | 含义 | 示例 |
|---|---|---|
| 所属单元 | 对应教材第几单元 | 三上·第二单元 |
| 知识点 | 一句话，可测 | 用多种方法理解难懂词语 |
| 掌握标准 | 做到什么算会 | 能对"憧憬""五彩缤纷"说出至少两种理解方法 |
| 对应题型 | 会以什么形式考 | 选择、填空、阅读理解 |
| 常见错误 | 真实错法，非泛泛而谈 | 只查字典不理解、望文生义 |
| 来源 | 教材页码或课标条目 | 统编版三上 P24 |

### 4.3 更新机制

| 时机 | 动作 |
|---|---|
| 每学完一个单元 | 补该单元知识点状态，归档该单元错题，更新掌握度 |
| 每周日 | 生成周报：本周新学 / 待巩固 / 连续天数 |
| 每月末 | 生成月报：四科进度、错因分布、体育数据趋势 |
| 期末 | 生成学期报告 + 寒暑假补漏清单 |
| 教材版本变化 | 只改 `01-教材底本`，其余按需迁移 |

### 4.4 检索方式

两种并存，不冲突：

1. **人读**：`knowledge/00-索引.md` 做总目录，按单元跳转；
2. **机读**：工具台"知识搜索"直接对 `knowledge/` 做全文检索，问答时作为上下文喂给模型，保证回答基于**这个孩子的课本和积累**，不是泛泛的网上内容。

## 五、实施路线

分四期，每期结束都是可用的，不是半成品。

### 第一期：对齐（解决"学错版本"）

- 按统编版新版重做 `chinese-g3up`：修正单元顺序，替换课文，删除旧版篇目，补 8 篇缺失
- 新建 `math-sujiao-g3up`：8 单元，约 45 个知识点
- 新建 `english-yilin-g3up`：8 单元 + 2 项目，26 字母轨道
- 建 `knowledge/` 目录与 `00-索引.md`
- **验收**：三科每个单元都能打开知识点课，且单元名与课本一致

### 第二期：补题型（解决"只会做选择题"）

- 新增题型：`application`（解决问题/应用题）、`short_answer`（简答）、`writing`（习作，接 AI 批改）、`listening`（听力，接 TTS）、`tracing`（字母书写）
- 语文补"看拼音写词语""课外阅读"
- 数学补两步计算应用题、单位换算、操作题
- 英语补字母书写、听音选图
- **验收**：三科各能出一份不含选择题的专项卷

### 第三期：试卷与积累（解决"学完就忘"）

- 试卷中心：单元自测卷 → 专项卷 → 期末整卷 → 错题重组卷
- 积累本页面：把 `knowledge/03-积累本` 渲染出来，支持增删、按单元筛选、导出打印
- 错题归档与错因诊断
- 体育模块：体质档案 + 每日打卡 + 技能图解
- **验收**：一份完整期末卷可自动组卷、自动判分、错题自动进积累本

### 第四期：闭环（解决"看不清进步"）

- 学情档案：掌握度热力图、错因分布、体育趋势
- 家长月报自动生成
- 个人最佳替代排行榜
- **验收**：月底能拿到一份可读的报告，指出"哪三个知识点最该补"

## 六、合规与红线

必须写进来，不是免责。

1. **考试定位**：小学三年级学校层面每学期仅一次期末考试，严禁周考、月考、单元考。工具台内所有试卷一律标注"自主练习 / 家庭自测"，不出现"考试""排名""分数段"字样。
2. **评价方式**：采用等级评价（优秀/良好/合格/待提高），不显示总分排名，不做班级对比。
3. **儿童数据**：孩子姓名、成绩、错题属个人信息，只存本地 `personal/`，不上传任何第三方，不做用户画像。
4. **不替代学校教学**：内容以课本为准，不超前、不拔高，三年级英语按零起点设计。
5. **体育安全**：运动项目标注强度与注意事项，不推荐无保护的高风险动作。

## 七、需要你拍板的事

方案到这里，有四件事我无法替你决定：

1. **当前进度锚点**：孩子现在语文、数学、英语各上到第几单元？我只能推算到"大约第 9 周"，但三个科目进度不一定同步。这决定第一期先补哪几个单元。
2. **落地形态**：是本地跑（桌面/浏览器，数据全在家）还是部署到云端（手机也能用，但要处理数据托管）？现有工程两种都支持。
3. **优先级**：四期里哪一期你最先要？如果是我建议——**第一期先做数学**，因为苏教版数学三上是整册空白，且计算是三年级的命门；语文重做量大，可以第二优先。
4. **体育数据来源**：学校的体测成绩单你有吗？有的话我按真实数据建模；没有的话就先做录入界面，等测试完再填。
