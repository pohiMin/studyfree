# 三年级学习工具台

苏州地区三年级（2026—2027 学年）家庭学习工具台。语文、数学、英语三科，纯静态页面，无需安装、无需联网即可使用。

**在线地址：** https://pohimin.github.io/studyfree/

---

## 有什么

| 科目 | 教材版本 | 题量 | 特色 |
|---|---|---|---|
| 语文 | 统编版 · 人民教育出版社 | 664 题 | 古诗默写、预测策略、文言文《司马光》、习作指导 |
| 数学 | 苏教版 · 江苏凤凰教育出版社 | 964 题 | 47 个教学视频推荐、错题变式题自动生成 |
| 英语 | 译林版（三年级起点）· 译林出版社 | 592 题 | 背单词闯关 70 词、判分容差 |

三科合计 2200 余题，均含期中、期末阶段检测。

## 怎么用

打开上述网址，或双击本地 `index.html`。

每个单元分三层难度：**基础**练会不会算，**提高**练会不会想，**挑战**练文字坑与逻辑。随堂自测限时计时，时间到自动交卷。做错的题自动进错题本，连对三次才移出。

学习记录全部保存在本机浏览器（localStorage），不上传任何服务器。

## 目录结构

```
index.html            Pages 门户入口（三科导航）
STATUS.md             项目现状：有什么、缺什么、怎么继续
demo/
  math-g3up/          数学工具台
  chinese-g3up/       语文工具台
  english-g3up/       英语工具台
  plan.html           学期学习规划
knowledge/
  01-教材底本/         三科单元清单（唯一事实源）
  04-真题库/           真实试卷存放处
```

每个科目目录下：`content/*.py` 是题库（Python 字典），`build.py` 是构建器，`out/` 是构建产物。

## 怎么改

改 `content/u*.py` 里的题目，然后：

```bash
cd demo/math-g3up
python build.py
```

构建时自动校验分值合计、答案越界、缺解析等错误，有问题不产出文件。

教材为 2025 年启用的新版，三科版本各不相同。网上大量"苏教版三上""统编版语文三上"资料仍是旧版，使用前请核对单元名。

全部测验均为自主练习，不计排名，不代替学校考试。
