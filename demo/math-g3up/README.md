## 怎么用

双击 `out/index.html` 从总览进入，或直接打开任意 `uN.html`。

**页面结构**

- **左上角是用户条**：头像、名字、星星总数，压在科目名上方
- **左侧是目录树**：九个单元；**当前单元展开成子目录** —— 7 个知识点 + 随堂自测 + 单元检测卷，点哪个右边显示哪个
- **右侧一张大卡片**：只显示当前选中的那一块，不再有分区标签栏，也不再有知识点胶囊
- **期中、期末**在同一套侧栏里，紧跟在九个单元后面；它们的「卷面」也是先点开始、再计时

**学知识点这一块**

- 上方是学习视频卡片（标题 + 关键词 + 时长 + 集数）
- 再往下是七个知识点的小标签，**一次只显示一个知识点**，点标签切换
- 每个知识点左右两栏：左边讲解（核心概念 / 关键规则 / 常见错误 / 小提示），右边先基础题再提高题
- 提高题有紫色标记和浅紫底，跟基础题一眼分得开

**答题**

选择判断题点完立刻判分，答错标红、正确答案标绿并给解析；填空题回车或点「检查」。答对后题目编号变绿、整块淡绿底，答错的变红。

### 视觉与字号的取舍

小学三年级孩子的注意力短，一屏全是小字会看不下去。所以做了这几件事：

| 做法 | 目的 |
|---|---|
| 基准字号 17px（原来 16px），题目 16px，讲解 15px | 放大到不费眼 |
| 选项按钮改成 1.5px 边框 + 11px 内边距的大块 | 好点、不易点错 |
| 知识点一次只显示一个 | 避免一屏十几道题的压迫感 |
| 单元子项目进左侧目录树 | 结构和层级一眼看清楚，右侧不再有多余的标签栏 |
| 单元整体收在一张卡片里 | 有"这是一个完整单元"的边界感 |
| 进度条蓝→绿渐变、答对整块变绿 | 给即时反馈，不是干巴巴的对错 |

没有加卡通角色、音效、动画。三年级的孩子对"幼稚化"其实敏感，做过头会反感。这里靠的是留白、色块和信息层级，不是靠花哨。

## 难度分层（三级）

原来只有基础题和提高题，现在加到三级：

| 层级 | 标记 | 考的是什么 |
|---|---|---|
| 基础题 | 无标记 | 会不会算 |
| 提高题 | 紫色「提高」 | 会不会想，两步推理 |
| 挑战题 | 橙色「挑战」 | 文字坑、隐藏条件、逆向推理、重叠计数、生活常识 |

挑战题的设计参考了江苏期末卷的高频难点，每道题的解析都会点明「坑在哪」。举几个：

- **多余条件**：给了红、蓝、黄三种气球的数，只问红气球还剩几个 —— 干扰项用不上
- **文字坑**：「实际比计划推迟了 3 天」，实际天数是 5+3=8 天，不是 3 天
- **逆向推理**：一根绳子两次各剪去一半，最后剩 5 米，原来多长 —— 要乘两次 2
- **重叠计数**：「从前数第 5、从后数第 8」，5+8 要减 1
- **隐含条件**：靠墙围菜地，靠墙那面不用围，求「至少」要选短的那种围法
- **至少/进位**：28 吨货每次运 3 吨，运 9 次还剩 1 吨，得算 10 次

## 期末检测卷

按 2025—2026 学年苏教版三年级上册期末卷的真实结构做：**70 分钟，100 分 + 附加题 10 分**。

| 大题 | 题数 × 分值 | 小计 |
|---|---|---|
| 一、直接写出得数 | 8 × 1 | 8 |
| 二、用竖式计算 | 4 × 3 | 12 |
| 三、脱式计算 | 4 × 3 | 12 |
| 四、填空 | 10 × 2 | 20 |
| 五、选择 | 6 × 2 | 12 |
| 六、根据数据填空 | 2 × 3 | 6 |
| 七、解决问题 | 5 × 6 | 30 |
| 八、附加题（不计入 100 分） | 2 × 5 | 10 |

难度是往上走的：前面的计算题保底，填空最后一题考重叠计数，选择最后一题考靠墙问题，解决问题的第 3 题埋了「推迟 3 天」的文字坑，附加题是倍数代换和倒推。

## 限时测验（随堂自测 + 单元检测卷 + 期中 + 期末）

这四项全部不是"边做边判"，而是**模拟一次限时测验**，走的是同一套引擎（`runTimedQuiz`）：

1. 点「开始」前看不到题目，也不能提前看答案
2. 开始后倒计时启动，**时间到自动交卷**，也可以提前点「交卷」
3. 作答过程中只记录、不判分，选择题点了可以改，填空题输了可以改
4. 顶部实时显示「已答 n / N 题」和剩余时间
5. 最后 60 秒倒计时变红闪烁
6. 交卷后倒计时停住并显示「已交卷」，不能再改答案

**限时怎么定**

| 项目 | 限时 |
|---|---|
| 随堂自测 | 题量 × 1 分钟（20 题 = 20 分钟） |
| 单元检测卷 / 期中 / 期末 | 内容里的 `paper.duration`，即出卷时定的建议时长（第一单元 40 分、期中 45 分、期末 70 分） |

交卷后出三样东西：**分数 + 星星 + 错题分析**。检测卷按分累计（第一单元 100 分、期末 100+附加 10），自测按答对题数。

> 点「重置本页」会同时停表、清空卷面、把按钮复位成「开始检测」——不会出现计时还在跑但题目被清掉的状态。

### 星星怎么给

| 正确率 | 星星 |
|---|---|
| 低于 60% | 1 颗 |
| 60% — 95% | 2 颗 |
| 高于 95% | 3 颗 |

> 你给的是「低于 60 得 1 星、61—95 得 2 星、大于 96 得 3 星」，60% 和 61% 之间、95% 和 96% 之间有缝。我按「低于 60 → 1 星，60 到 95 → 2 星，高于 95 → 3 星」处理，这样每个百分比都有归属。要改判断阈值，改一行即可：
> ```js
> const stars = pct < 60 ? 1 : (pct <= 95 ? 2 : 3);
> ```

## 用户条与星星

用户条在**左上角**，压在科目名（三年级数学 / 苏教版·上册）上方：**头像 + 名字 + 已获得星星总数**。

### 星星怎么算

四种测验都产生星星：

| 测验 | 存储键 |
|---|---|
| 随堂自测 | `u{单元号}:exam` |
| 单元检测卷 | `u{单元号}:paper` |
| 期中检测 | `mid` |
| 期末检测 | `final` |

**每项只记最高一次，不重复累计。**考完一次 3 星、再考一次 1 星，仍然是 3 星；同一项考十次也只算一次。想把星星刷多，只能去考别的项目，或者把低分的项目提上去。

评级规则与其他测验一致：正确率低于 60% 给 1 星，60%—95% 给 2 星，高于 95% 给 3 星。

### 存在哪

`localStorage` 的 `math3.profile.v1`：

```json
{
  "name": "小明",
  "color": 2,
  "stars": { "u1:exam": 3, "u1:paper": 2, "mid": 3 }
}
```

改名字、换头像颜色、星星记录都在这个键里，不上传。

## 错题自动生成同类型题

答错一道题，除了原题进易错题本，还会**自动生成一道同类型的新题**一起放进去，在错题本里标「变式题 · 由原错题自动生成」。

两种生成方式，按顺序尝试：

1. **算式扰动**：题目是纯算式（如 `5×3+50=（ ）`）时，把里面每个数字随机换成同量级的数，重新计算答案。生成后校验必须是正整数，除不尽或出现零就重试，最多 16 次。
2. **题池抽取**：算式题生成不了（应用题、图形题），就从同知识点、同题型、还没做过的题里抽一道。

两种情况都失败才不生成。实测 20 道错题能生成 20 道变式，没有漏的。

## 易错题本（连续答对 3 次移出）

做错的题自动收进错题本，**跨单元汇总**。同一道题**连续答对 3 次**就自动移出；中途答错一次，连对次数清零重算。

### 为什么是 3 次

1 次可能是蒙对的，2 次可能只是刚记住，3 次分散在不同时间做对，才算真掌握。

要改次数，改两处即可：

```js
const WB_NEED = 3;   // template_unit.html 和 template_review.html 各有一处
```

### 存在哪里

浏览器 localStorage，键名 `math3.wrongbook.v1`。不联网、不上传、不出本机。

**已实测**：`file://` 双击打开和 `http://` 本地服务两种方式都能正常读写，且跨页面共享有效（在 u1 答错，打开 review.html 能读到）。

清空办法：浏览器设置里清理该站点数据。单元页底部的「清空本页作答记录」只清当前页的答题状态，**不动错题本**。

### 界面上怎么用

- 左侧栏「易错题本」后面跟一个红色数字，是当前待攻克的数量
- 进去后按来源分组（哪个单元、哪个知识点）
- 每题上方有三个小格，答对一格亮一个
- 第 3 个亮起 → 提示「已移出错题本」，题目淡出消失
- 全部清空时显示一张鼓励页

## 期中阶段检测

覆盖第一至第四单元（混合运算、乘法、统计、长度单位）。34 题，满分 100，建议 45 分钟。

卷面结构：直接写出答案 10×2=20 分｜填空 8×2=16 分｜选择 6×3=18 分｜计算 6×3=18 分｜解决问题 4×7=28 分。

定位是**自主检测，不是学校考试**。教育部规定义务教育其他年级每学期由学校组织一次期末考试、严禁区域性或跨校考试，所以这里明确标注「不计排名、不代替学校考试」。

## 教学视频推荐（外部跳转）

视频区是**推荐卡片**，不内嵌播放。每张卡片给出课时标题、知识关键词、时长、对应集数，点击在新窗口打开。

### 为什么放弃内嵌

试过三种 embed 地址，只有 `html5mobileplayer.html` 能渲染，而且不同环境下表现不稳定。与其做一个时好时坏的播放器，不如直接跳转——B站页面本身播放体验更好，还能倍速、选集、看弹幕。

### 已知缺口

**第四单元缺「认识毫米」**——合集里只有「认识分米」「认识千米」「练习六」，没有单独讲毫米的一集，所以该单元只有 3 个视频。毫米的部分内容在「认识分米」里带过，但不够系统。

### 加自己的视频

改 `content/uX.py` 的 `videos` 数组：

```python
{"title": "视频标题",
 "keywords": ["关键词1", "关键词2"],
 "source": "来源说明",
 "ep": "第 N 集",
 "duration": "12:30",
 "kind": "official",     # official / douyin / 其他
 "tag": "同步课",
 "url": "https://..."}   # 必须指向具体视频，不能填账号主页
```

### 关于抖音

搜过，抖音的独立视频链接（`douyin.com/video/{id}`）很难从公开搜索稳定拿到，链接失效也快。所以本版没有放抖音内容——你要求指向独立视频而非账号主页，这一条守住了。

要加的话把具体视频链接发过来，验证能打开就填进去。

## 怎么改内容

所有内容都在 `content/u1.py` ~ `u9.py`，是普通 Python 字典，直接用文本编辑器改。改完运行：

```bash
python build.py
```

构建时会自动校验：选择题答案必须在选项范围内、判断题答案必须是「对/错」、填空题必须有答案、每题必须有解析。任何一项不过，**不会产出文件**，避免把错题发出去。

## 迁入正式工程要改的地方

不迁也可以用——`out/` 整个目录丢给浏览器就能打开，适合先给孩子用起来。要并入平台则需处理以下几处：

1. **拆数据**（主要工作量）
   当前是一单元一个文件，工程是「一知识点一文件 + 一单元一试卷文件」。
   `data/u1.json` 的 `knowledgePoints[i]` → `lessons/math-sujiao-g3up-u1-kp{i+1}.json`，
   `exam` → `lessons/math-sujiao-g3up-u1-exam.json`，另需生成 `outline.json`。

2. **补字段**
   工程需要 `kpIndex`、`kpTotal`、每题 `knowledge_point`。本项目的 `core_concept / key_formula / common_mistakes / tips` 已按工程字段命名，可直接映射。

3. **题型对齐**
   `choice` / `true_false` 可直接用；本项目 `input`（带单位、数值判定）需落到工程的 `fill_blank`，或在工程里加一个「带单位数值作答」的分支。

4. **注册**
   在 `apps/web/public/data/books/index.json` 登记 `math-sujiao-g3up`，确认 `publishers.ts` 的 `math-sujiao-` 前缀规则覆盖三年级。

5. **路由**
   本版本是「一单元一页」的聚合视图，工程是「一课一时」。
   两个选择：拆成课时页；或保留单元总览页作为新增路由。**建议保留总览页**——家长按单元看进度比按课时翻更直观。

## 已知不足

- **第八单元（观察物体）光看题练不出来**。教材要求动手摆小正方体，本版只有文字描述的视图判断题，能判断「从右面看是几个」，但建立不了真正的空间感。要补必须做可拖拽的积木组件。
- **应用题只判最终数值**，不判算式。孩子列式错了但算对了同一个数，会判对。三年级先放过，避免误伤不同解法。
- **没有配图**。几何、观察物体这两块受影响最大，其他单元影响不大。
- **没有掌握度、错题归档、间隔复习**。这些要接工程已有的 `srs.ts` 和 `personal/`，本版是静态页面。
- **移动端未实测**。布局用了响应式网格，但没在真机上验证过。
- **视频只有一套来源**。47 集全部来自同一个B站合集，优点是按课时精准对应、不重不漏；缺点是只有一位老师讲，没有第二种讲法可对比。第四单元还缺「认识毫米」。
- **视频不内嵌**，点击会跳出到B站。这是主动取舍，不是缺陷。
