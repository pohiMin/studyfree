# 语文学习台 · 统编版三年级上册

与 `demo/math-g3up` 同一套架构的语文版：纯静态、数据即代码、构建即校验。

## 快速开始

双击 `首页.html`（demo 目录）选语文，或双击 `启动学习台.bat` 起本地服务后访问
`http://127.0.0.1:8899/index.html`。改动 `content/uX.py` 后重新运行 `build.py` 即可。

## 与数学版的差别

- 没有「教学视频」区：语文未找到可与教材逐课对应的可验证合集，宁可不放，不塞未验证的链接。
- 填空题答案是汉字词语，判分自动忽略空格和全半角标点。
- 卷面大题结构固定七段（读音/选字/补词/选词/判断/按课文填空/阅读表达），单元检测卷 34 题 100 分、限时 40 分钟。

## 事实核对记录

## 登录与账号（login.html / accounts.html）

- **学习台已上锁**：三科所有页面（单元 / 总览 / 错题本 / 背单词）必须登录才能进入，
  未登录访问一律跳转登录页，登录后自动回到原页。
- **账号制登录**：login.html 输入**登录账号 + 密码**登录。账号由家长创建，登录页不能自行注册。
- **账号权限管理**：demo/accounts.html（家长专区，首次进入需设置管理员密码）。
  建号字段：**姓名、学校、班级、登录账号（3–12 位英文字母+数字）、密码**；
  其他功能：改登录密码、删号（同时清除该账号全部学习记录）。
- **姓名与账号分工**：数据 key 与登录会话用登录账号（纯字母数字）；学习台用户条默认显示
  **姓名**（模板 __DISP 注入），改名仍可点用户条铅笔修改。
- **旧账号迁移**：升级前的姓名账号登录时输姓名当账号：无密码的会要求补设，有密码的直接登录。
- **密码安全**：SHA-256 加盐哈希存储；数据只在本机浏览器，换设备不跟随。
  忘记管理员密码：清除浏览器本站数据即重置（会连带清除全部学习记录）。


## 多解填空的判分规则（2026-10-29）

语文（以及三科共用）填空题存在「答案不唯一」的情况，判分分三层处理：

1. **多答案数据**：`answer` 支持 `"主答案|备选1|备选2"`，命中任一即判对。
   例：`"唱歌|跳舞|歌唱|微笑|招手|嬉戏"`。显示时自动渲染为「唱歌 或 跳舞 或 …」，
   提示语统一用「参考答案」而不是「正确答案」。
2. **「算我对」按钮**：系统外但语义正确的答案被判错时，反馈下方会出现
   「我填的也对 · 算我对」按钮。点一下：反馈转绿、计入答对、**撤销刚记入的错题
   （含自动生成的变式题）**。
3. **交卷后逐题改判**：随堂自测 / 检测卷交卷后，错题分析里每条填空题带
   「我答的也对 · 算对这题」按钮。点击后重算分数与正确率、星星只升不降、错题数减一。
4. **错题本复习**同样支持「算我对」：改判为答对，连对次数 +1（满 3 次移出）。

判分归一化（norm）在三科原有基础上追加：去中文引号、书名号、句号问号叹号分号冒号——
孩子答题时不写标点也能判对。


## AI 复核（可选，2026-10-29）

填空判错时，可以让 AI 再判断一次「这个答案在语义上是否也算对」。**默认关闭**，不配置就完全走原有规则。

**开启方式**：家长专区（accounts.html）→ 解锁 →「AI 复核（可选）」→ 勾选开关 →
填 API 地址（OpenAI 兼容的 `…/chat/completions`）、模型名、API Key → 保存 → 点「测试连接」确认可用。

**设计边界（重要）**：

- **Key 只存这台设备的 localStorage**，不写进任何代码或文件，因此公开仓库/线上站点里没有 Key。
  代价：换设备要重填；公共设备上孩子可能翻到 Key。
- **只复核填空题判错**：选择题、判断题、数学计算题不参与，避免把本该严格的题判松。
- **只放宽、不收紧**：规则判对的题永远不会被 AI 改判错。最坏情况是漏放，不会误伤。
- **异步不阻塞**：判错与提示照常立刻出现，AI 结果晚一步返回；命中则自动改判为对、
  撤销刚记的错题（含变式题），反馈显示「AI 复核：这个答案也算对」。
- **结果缓存**（`studyfree.aifix.v1`）：同一题干+答案只问一次，既省钱又保证同一答案每次结果一致。
- **失败静默**：未配置、断网、6 秒超时、接口报错——一律安静跳过，判错照旧，「算我对」按钮仍在。
- **隐私**：开启后，题目文本和孩子填的答案会发送给所选 API 服务商。家长知情后再开。

**开发测试**：`demo/_mock_ai.py` 是本地 mock（可切换返回「对/错/500」并统计请求数），
`chinese-g3up/test_ai.mjs` 依赖它做 14 项端到端验证。


## 作答记录持久化（2026-10-29）

基础题（知识点区）答过的题不再刷新即丢：

- 存储：`<科目>3.done.v1.<登录账号>`，结构 `{ "p<单元号>": { "qid": {ok, ua, ts} } }`。
  按单元分页存，避免不同单元的 `kp0_0` 互相覆盖；期中 `p0`、期末 `p-1`。
- 恢复：重进页面时，已答的题自动还原成答完的样子——输入框保留孩子写的答案、禁用、
  边框按对错着色；答错的题保留「算我对」按钮。选择题会标出正确项与误选项。
- 进度：顶部「已完成 n / N」跨会话保留。
- 清除：「重置本页」同时清空作答记录（否则刷新会回来），并有二次确认。
- 隔离：记录按登录账号分开，切换使用者互不影响；自测与检测卷的卷面不恢复（每次重新开始），
  但交卷后的题目计入进度。
