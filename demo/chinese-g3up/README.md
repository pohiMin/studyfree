# 语文学习台 · 统编版三年级上册

与 `demo/math-g3up` 同一套架构的语文版：纯静态、数据即代码、构建即校验。

## 快速开始

双击 `首页.html`（demo 目录）选语文，或双击 `启动学习台.bat` 起本地服务后访问
`http://127.0.0.1:8899/index.html`。改动 `content/uX.py` 后重新运行 `build.py` 即可。

## 与数学版的差别

- 没有「教学视频」区：语文未找到可与教材逐课对应的可验证合集，宁可不放，不塞未验证的链接。
- 填空题答案是汉字词语，判分自动忽略空格和全半角标点。
- 卷面大题结构固定七段（读音/选字/补词/选词/判断/按课文填空/阅读表达），单元检测卷 34 题 100 分、限时 40 分钟。

## 事实核对记录

- 古诗六首原文逐字核对（山行/赠刘景文/夜书所见/鹿柴/望天门山/饮湖上初晴后雨）。
- 文言文《司马光》按课文原句出题，标注「柴」读 zhài、「没」读 mò、「景」通「影」。
- 民族名称读音（傣 dǎi、景颇 jǐng pō、阿昌 ā chāng、德昂 dé áng）已核对。
- 课文细节题仅使用可确定的原文内容（两只猴子、四个胃、六十九小时等）。
- 「日积月累」课本内页未核对，相关内容暂未出题（见底本第五节待确认项）。

## 校验

`build.py` 构建时自动校验：题型合法性、选择答案越界、缺解析、检测卷分值合计必须等于满分。
uitest.py 自动答题回归九页全过。
